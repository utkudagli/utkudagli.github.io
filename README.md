# utkudagli.com

Personal portfolio of **Utku Dağlı — Game & Technical Designer**.

**Live site:** [www.utkudagli.com](https://www.utkudagli.com)

Built from scratch in vanilla **HTML, CSS and JavaScript** — no frameworks, no site builder, no template but with the help of AI. All content is data-driven from a single `main.js`, rendered client-side.

## What's on the site

- **Projects** — [Mawforged](https://store.steampowered.com/app/3373310/Mawforged/) (UE5, in development at Axiosys), [Heretic](https://utkudagli.itch.io/heretic) (UE5 solo research prototype for my master's thesis on punishment mechanics), [Sabotaj](https://store.steampowered.com/app/1436900/Sabotaj/) (UE4, shipped on Steam), and VR/AR work
- **Resume** — embedded PDF with download
- **Certificates** — Google UX Design Professional Certificate

## Structure

```
index.html          Home: hero, projects, skills, background
resume.html         CV viewer
certificates.html   Certificate viewer
main.js             All content data + render functions
styles.css          All styling
Projects/           Project images
Documents/          PDFs (CV, certificates)
```
